# Notebook

Place the documented Jupyter notebook version of the workflow in this directory.

Recommended filename:

```text
varvamp_qpcr_workflow.ipynb
```

The Python script at the repository root is the main command-line implementation.
The notebook can be retained for explanation, visualization, and teaching.

GitHub displays notebooks statically. Use Jupyter, GitHub Codespaces, or another
compatible environment to execute the cells.
